How to read the catalog

Classification tags can overlap. A magnetic-CV tag follows the audited catalog bin; adjacent wording qualifies candidate or disputed subclasses. Host confidence is separate from radio confidence. Radio labels retain published wording: no uniform detection threshold is imposed. Blank values mean unselected or unreported, never zero. Exact Gaia IDs are text. Select column headings to sort; missing values stay last.

Filled symbols indicate established hosts without a flagged subclass interpretation; open symbols indicate qualified host or subclass status. Symbol groups are display priorities, not exclusive classifications: transient, WD pulsar, magnetic-CV tag, then other CV. ASKAP J174508.9-505149 retains both transient and proposed magnetic-CV tags.
