Radio evidence across white-dwarf systems.

A literature-curated catalog of radio observations and reported emission from white-dwarf systems and related candidates. Explore each system’s observations, component-specific properties and supporting evidence.

Membership includes reported detections, marginal signals and explicit upper limits. The sample is neither complete nor uniformly surveyed; overlapping classes do not establish a shared evolutionary sequence.

How to read the catalog

Classification tags can overlap. A magnetic-CV tag follows the audited catalog bin; adjacent wording qualifies candidate or disputed subclasses. Host confidence is separate from radio confidence. Radio labels retain published wording: no uniform detection threshold is imposed. Blank values mean unselected or unreported, never zero. Exact Gaia IDs are text. Radio observations counts the cataloged observation records for each system, including detections, marginal signals and upper limits; it is not a count of detections. Orbit and distance are displayed to two decimal places; source details and downloads retain their precision. Select column headings to sort using the stored values; missing values stay last.

Filled symbols indicate established hosts without a flagged subclass interpretation; open symbols indicate qualified host or subclass status. Symbol groups are display priorities, not exclusive classifications: transient, WD pulsar, magnetic-CV tag, then other CV. ASKAP J174508.9-505149 retains both transient and proposed magnetic-CV tags.
